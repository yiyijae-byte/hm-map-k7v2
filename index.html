신청 방법

흐름은 세 기관 모두 같습니다. 공고 확인 → 접수 기간에 인터넷 청약 → 서류심사 대상자 발표 → 서류 제출 → 당첨 또는 예비번호 → 빈집이 나오면 순번대로 계약. 소득과 자산은 신청할 때 "정보 조회 동의"를 하면 기관이 조회하고, 직접 내는 서류는 보통 주민등록등본, 초본, 청약통장 확인서입니다.

  • SH (서울) 인터넷청약시스템 로그인(공동인증서 필수) → 청약신청 → 공고 선택 → 단지, 평형 선택 → 접수. 며칠 뒤 공고 게시판에 서류심사 대상자 발표가 뜨면 그때 서류를 냅니다.
  • LH 청약플러스 로그인 → 청약 → 임대주택 → 공고의 청약신청 → 유형, 단지, 주택형 선택 → 접수. 공고문에 "현장접수"라고 적힌 매입임대, 전세임대는 주거복지지사에 직접 방문합니다.
