지난 공고 주기로 짐작한 일정이라 실제와 다를 수 있습니다. 미리 인증서와 서류를 준비해두는 용도입니다.

신청 방법

공통 흐름

공고 확인 → 접수 기간에 청약 → 서류심사 대상자 발표 → 서류 제출 → 당첨 또는 예비번호 → 빈집이 나오면 순번대로 계약. 소득과 자산은 "정보 조회 동의"로 기관이 조회하고, 직접 내는 서류는 보통 주민등록등본, 초본, 청약통장 확인서입니다.

SH (서울)
  • 인터넷 청약 공고: SH 인터넷청약시스템 로그인(공동인증서 필수) → 청약신청 → 공고 선택 → 단지, 평형 선택 → 접수. 접수 기간이 아니면 목록이 비어 있습니다.
  • 방문 접수 공고(일반 매입임대 등): 어머니 주소지 동 주민센터에 신분증, 도장을 들고 방문. 신청서와 동의서는 창구에 있습니다.
  • 서류는 며칠 뒤 공고 게시판에 "서류심사 대상자 발표"가 뜨면 그때 냅니다.
LH
  • LH 청약플러스 로그인 → 청약 → 임대주택 → 공고의 청약신청 → 유형, 단지, 주택형 선택 → 접수.
  • 공고문에 "현장접수"라고 적힌 매입임대, 전세임대는 주거복지지사에 직접 방문합니다.
GH (경기, 의왕)
  • GH 청약센터 로그인 → 임대주택 청약공고 → 공고 선택 → 신청.

출처: LH 청약플러스, SH 공고 게시판, GH 청약센터, 마이홈포털 예비입주자 대기현황. 매일 저녁 8시 갱신.
